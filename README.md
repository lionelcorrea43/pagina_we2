Temática: Página Deportiva.
Descripción: La páginas permite visualizar instituciones deportivas(en este caso clubes de Argentina) y también permite ver que jugadores integran dichas instituciones. Cada institución es única al igual que sus jugadores. Cada usuario debera registrarse y luego debera loguearse mediante un formulario de login. Por defectos todos seran usuarios a exepcion de una cuenta q sera Administrador(previamente cargada). Este cuenta administradora tendra acceso a funciones de editar, eliminar y agregar dentro de la pagina. En caso de no estar logueado el contenido de la pagina se limitara al formulario de Login y Registro.
Como abrir el sitio:
1- Se debe bajar este repositorio en su maquina local.
2- Debera tener previamente el Xampp instalado.
3- Crear una copia del repositorio en la carpeta Htdocs que se encuantra dentro de la carpeta Xampp.
3- Debera activar los servicios de Apache y SQL mediante Xampp Control para poder tener acceso a la pagina desde su navegador.
4- Mediante el archivo .SQL que se le brinde debara cargar la base de datos en la pagina PhpMyAdmin.
5- Abrir la pagina poniendo "http://localhost/repositorio-descargado.
6- Una vez dentro debera loguearse, los usuarios deben registrarse previamente y el administrador podra hacerlo con la siguiente cuenta:
email: webadmin.
password: admin.
